## High-level view

文書権限と保存済みは、URL queryを選択状態の正本にしたmanual activation tabです。応答はactive panelだけを描画し、全tabの`aria-controls`をその応答内の単一tabpanelへ向け、クライアント側はfocus移動とSpace activationだけを担当します。

文書権限の両viewは既存RTP keyを維持し、同じfilterを25件paginationと全件CSVへ適用します。remote picker、public_id route、admin-only gate、maintenance-modeのmutation停止境界も維持されています。

管理Dashboardは要対応・主要件数・最近の問題に縮約され、設定診断、storage、モデル観測、継続失敗候補はadmin-onlyのDiagnosticsへ移されています。共通Concernにより、短い入口と詳細表示が同じ失敗集計を共有します。

主要一覧と閲覧可能文書は初期表示を短くし、監査ログはHTML 50件、最新CSV 200件、表示ページCSV 50件を分離しました。一括編集はpayloadを変えず対象表をスクロール領域へ閉じています。

custom screenshotは7つの状態名付きtargetを追加し、文書権限と保存済みのgeneric indexを重複撮影しません。一時出力への実撮影で7 target、49 screenshot、37 group、unclaimed 0件を確認しました。

## server-rendered tabとbookmark mutation境界

`server-rendered-tabs`は選択tabだけをTab順へ置き、ArrowLeft / ArrowRightを循環、Home / Endを端へ移動させます。矢印操作はfocus移動だけ、Spaceはclick、Enterはanchorのnative activationとなるmanual activation契約です。request specは全tabの`aria-controls`が応答内のactive panelを参照すること、active panel以外がSSRされないこと、roving tabindexとStimulus接続を固定しています。

bookmarkの復元specは、閲覧不能文書へのcreate/moveが403でDBを変更しないこと、他ユーザーbookmarkが404になること、重複createを作らないこと、既存favorite付きmoveでfavoriteを増やさずread-laterだけを削除することを検証しています。

## 文書権限のactive view、pagination、CSV

`view`はassignments / overviewにallowlistされ、不正値はassignmentsへ戻ります。両viewは安定順序を持ち、filterとviewをpagerへ保持します。CSVはpaginated instance variableではなく同じfilter済みrelation全体から生成されます。

RTP keyは`admin_document_permissions`、`admin_document_permission_overview`を含め全対象画面で既存値を維持しています。Gemfile / lockfile、package manifest、routes、DB schema、migrationには差分がありません。

## DashboardとDiagnosticsの責務分離

Dashboardは4主要モデル、3要対応metric、最新問題最大5件だけを表示し、Diagnosticsは設定filter、文書実体健全性、storage内訳、全モデル観測、失敗候補とdigest/runbook導線を引き受けます。移動したDashboard specは対象pathとview sourceだけをDiagnosticsへ変更し、failure candidate link、digest、storage breakdownの検証内容を保持しています。

## list-first、監査ログ、一括編集

Users / Projects / Documentsは新規フォームをvalidation error時だけ開くDisclosureへ移し、検索toolbar、filter chip、件数、RTP editor、table、paginationの順へ再構成しています。`/documents`の低頻度条件は同じGET form内に残り、RTP key、filter param、認可scopeを維持します。

監査ログは`accessed_at desc, id desc`を保って1ページ50件・最大10,000行とし、latest exportだけ200件を維持します。metadataもlatest/current pageの上限を反映します。一括編集はdocument id checkboxとhandoff POSTを同じform内に保ち、対象表だけを450pxのfocus可能なscroll regionへ移しています。
